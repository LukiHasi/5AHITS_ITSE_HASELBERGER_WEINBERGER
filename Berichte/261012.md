# PHP Basics
Kurze Übersicht zu den wichtigsten Grundlagen aus den W3Schools-Tutorials. Praktisch als Spickzettel beim Coden.

---

## 1. Das Wichtigste vorab

* Code kommt immer in `<?php ... ?>`.
* Jede Anweisung muss mit einem Semikolon `;` enden.
* Kommentare: `//` für Zeilen, `/* ... */` für Blöcke.

```php
<?php
// So startet man
echo "Hello World!";
?>
```

---

## 2. Variablen & Typen

* Variablen starten immer mit einem `$`.
* PHP erkennt Datentypen automatisch (String, Int, Float, Bool, Array, Object, NULL).
* Strings verknüpfen mit einem Punkt `.`.

```php
$name = "Alex";
$alter = 25;
$aktiv = true;

// Ausgabe mit String-Verkettung
echo "Name: " . $name . " (" . $alter . ")";

// Geht auch direkt im String mit doppelten Anführungszeichen
echo "Hallo $name!";
```

### Konstanten
Bleiben unveränderlich und brauchen kein `$`.

```php
define("DB_HOST", "localhost");
echo DB_HOST;
```

---

## 3. Wichtige Operatoren

* **Rechnen:** `+`, `-`, `*`, `/`, `%` (Modulo)
* **Zuweisungen:** `=`, `+=`, `-=`
* **Vergleiche:**
  * `==` vergleicht nur den Wert (`"5" == 5` ist wahr).
  * `===` vergleicht Wert **und** Typ (`"5" === 5` ist falsch).
  * `!=` oder `<>` (ungleich).
* **Logik:** `&&` (und), `||` (oder), `!` (nicht)

## 4. Bedingungen (If / Switch)

```php
$stunde = 14;

if ($stunde < 12) {
    echo "Morgen!";
} elseif ($stunde < 18) {
    echo "Tag!";
} else {
    echo "Abend!";
}

// Wenn man viele feste Werte abfragt:
$rolle = "admin";

switch ($rolle) {
    case "admin":
        echo "Vollzugriff";
        break;
    case "user":
        echo "Eingeschränkt";
        break;
    default:
        echo "Gast";
}
```

## 5. Schleifen

```php
// Standard for-Schleife
for ($i = 0; $i < 5; $i++) {
    echo "Durchlauf $i <br>";
}

// While
$nr = 1;
while ($nr <= 3) {
    echo $nr;
    $nr++;
}

// Foreach – super wichtig für Arrays!
$farben = ["Rot", "Grün", "Blau"];

foreach ($farben as $farbe) {
    echo $farbe . "<br>";
}
```

## 6. Arrays

PHP unterscheidet im Prinzip zwischen zwei Array-Arten:

```php
// 1. Indiziert (nummeriert ab 0)
$tiere = ["Hund", "Katze", "Maus"];
echo $tiere[0]; // Hund

// 2. Assoziativ (Key-Value-Paare)
$user = [
    "name" => "Max",
    "alter" => 30,
    "stadt" => "Berlin"
];

echo $user["name"]; // Max

// Durch assoziatives Array iterieren:
foreach ($user as $key => $value) {
    echo "$key: $value <br>";
}
```

## 7. Funktionen

```php
// Funktion mit Default-Wert und Return
function berechneSumme($a, $b = 10) {
    return $a + $b;
}

$ergebnis = berechneSumme(5); // 5 + 10 = 15
```

## 8. Formulardaten abfangen (`$_GET` & `$_POST`)

Superglobale Variablen, um Daten von Forms oder aus der URL zu lesen:

```php
// Wenn Formular via GET abgeschickt wurde (z.B. index.php?search=php)
$suche = $_GET['search'] ?? '';

// Wenn Formular via POST gesendet wurde
if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $email = $_POST['email'];
}
```

> **Tipp für die Praxis:** Eingaben vor der Ausgabe immer mit `htmlspecialchars($eingabe)` bereinigen, um XSS-Lücken zu vermeiden.
