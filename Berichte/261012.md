## 1. Wichtige Grundlagen

* Code kommt immer in `<?php ... ?>`.
* Jede Anweisung muss mit einem Semikolon `;` enden.
* Kommentare: `//` für Zeilen, `/* ... */` für Blöcke.

```php
<?php
// So startet man
echo "Hello World!";
?>
```

---

## 2. Variablen & Typen

* Variablen müssen immer mit einem `$` begonnen werden.
* PHP erkennt Datentypen automatisch (String, Int, Float, Bool, Array, Object, NULL).
* Strings verknüpfen mit einem Punkt `.` anstelle des `+` in **C#**.

```php
$name = "Alex";
$alter = 25;
$aktiv = true;

// Ausgabe eines verketteten Strings
echo "Name: " . $name . " (" . $alter . ")";

```

### Konstanten
Bleiben unveränderlich und brauchen kein `$` zur definition.

```php
define("DB_HOST", "localhost");
echo DB_HOST;
```

---

## 3. Wichtige Operatoren

* **Rechnen:** `+`, `-`, `*`, `/`, `%` (Modulo)
* **Zuweisungen:** `=`, `+=`, `-=`
* **Vergleiche:**
  * `==` vergleicht nur den Wert (`"5" == 5` ist wahr).
  * `===` vergleicht Wert **und** Typ (`"5" === 5` ist falsch).
  * `!=` oder `<>` (ungleich).
* **Logik:** `&&` (und), `||` (oder), `!` (nicht)

---

## 4. Bedingungen (If / Switch)

```php
$stunde = 14;

if ($stunde < 12) {
    echo "Morgen!";
} elseif ($stunde < 18) {
    echo "Tag!";
} else {
    echo "Abend!";
}

// Wenn man viele feste Werte abfragt:
$rolle = "admin";

switch ($rolle) {
    case "admin":
        echo "Vollzugriff";
        break;
    case "user":
        echo "Eingeschränkt";
        break;
    default:
        echo "Gast";
}
```

## 5. Schleifen

```php
// Standard for-Schleife
for ($i = 0; $i < 5; $i++) {
    echo "Durchlauf $i <br>";
}

// While
$nr = 1;
while ($nr <= 3) {
    echo $nr;
    $nr++;
}

// Foreach – super wichtig für Arrays!
$farben = ["Rot", "Grün", "Blau"];

foreach ($farben as $farbe) {
    echo $farbe . "<br>";
}
```

---

## 6. Arrays

In php wird grundsätzlich zwischen 2 verschiedenen Arte  unterschieden

```php
// 1. Indiziert (nummeriert ab 0)
$tiere = ["Hund", "Katze", "Maus"];
echo $tiere[0]; // Hund

// 2. Assoziativ (Key-Value-Paare)
$user = [
    "name" => "Max",
    "alter" => 30,
    "stadt" => "Berlin"
];

echo $user["name"]; // Max

// Durch assoziatives Array iterieren:
foreach ($user as $key => $value) {
    echo "$key: $value <br>";
}
```

---

## 7. Funktionen

```php
// Funktion mit Default-Wert und Return
function berechneSumme($a, $b = 10) {
    return $a + $b;
}

$ergebnis = berechneSumme(5); // 5 + 10 = 15
```

## 8. Formulardaten abfangen (`$_GET` & `$_POST`)

Sind dazu da, um Daten von Forms oder aus der URL zu lesen:

```php
// Wenn Formular via GET abgeschickt wurde (z.B. index.php?search=php)
$suche = $_GET['search'] ?? '';

// Wenn Formular via POST gesendet wurde
if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $email = $_POST['email'];
}
```
Je nachdem, welche Abfrage verwendet wird, werden die Informationen anders eingelese.

**GET:** Die Daten stehen direkt in der URL im Klartext und können somit gelesen werden.<br>
**POST:** Die Daten werden im Hintergrund (im Body) an den Server gesendet.

## Notenverwaltung

**Aufgabenstellung:** <br>

- Mehrere Noten über ein Formular eingeben
- Noten in einem Array speichern
- Durchschnitt, beste/schlechteste Note und Anzahl der Positiven Noten berechnen
- Ausgabe in einer HTML-Tabelle

```
<?php

$noteneingegeben = false;


$noten = [
    "einser"  => 0,
    "zweier"  => 0,
    "dreier"  => 0,
    "vierer"  => 0,
    "fuenfer" => 0
];


if(isset($_POST['einser']) || isset($_POST['zweier']))
{
    $noten['einser']  = (int)$_POST['einser'];
    $noten['zweier']  = (int)$_POST['zweier'];
    $noten['dreier']  = (int)$_POST['dreier'];
    $noten['vierer']  = (int)$_POST['vierer'];
    $noten['fuenfer'] = (int)$_POST['fuenfer'];
    
    $noteneingegeben = true;
}
?>

<?php
if($noteneingegeben == false)
{
    ?>
    
    <form method="post">
        Anzahl Einser: <input type="number" name="einser"><br><br>
        Anzahl Zweier: <input type="number" name="zweier"><br><br>
        Anzahl Dreier: <input type="number" name="dreier"><br><br>
        Anzahl Vierer: <input type="number" name="vierer"><br><br>
        Anzahl Fünfer: <input type="number" name="fuenfer"><br><br>

        <input type="submit" value="Noten hinzufügen">
    </form>

    <?php
}

if($noteneingegeben == true)
{
    $gesamtAnzahl = $noten['einser'] + $noten['zweier'] + $noten['dreier'] + $noten['vierer'] + $noten['fuenfer'];
    
    if ($gesamtAnzahl > 0) {

        $punktSumme = ($noten['einser'] * 1) + 
                      ($noten['zweier'] * 2) + 
                      ($noten['dreier'] * 3) + 
                      ($noten['vierer'] * 4) + 
                      ($noten['fuenfer'] * 5);
        
        $durchschnitt = round($punktSumme / $gesamtAnzahl, 2);
    } else {
        $durchschnitt = 0;
    }

   
    $besteNote = "-";
    if ($noten['einser'] > 0) $besteNote = 1;
    elseif ($noten['zweier'] > 0) $besteNote = 2;
    elseif ($noten['dreier'] > 0) $besteNote = 3;
    elseif ($noten['vierer'] > 0) $besteNote = 4;
    elseif ($noten['fuenfer'] > 0) $besteNote = 5;

    $schlechteNote = "-";
    if ($noten['fuenfer'] > 0) $schlechteNote = 5;
    elseif ($noten['vierer'] > 0) $schlechteNote = 4;
    elseif ($noten['dreier'] > 0) $schlechteNote = 3;
    elseif ($noten['zweier'] > 0) $schlechteNote = 2;
    elseif ($noten['einser'] > 0) $schlechteNote = 1;


    $positiveNoten = $noten['einser'] + $noten['zweier'] + $noten['dreier'] + $noten['vierer'];

    ?>
    <table border="1" cellpadding="5" cellspacing="0">
        <tr>
            <th>Statistik</th>
            <th>Wert</th>
        </tr>
        <tr>
            <td>Einser</td>
            <td><?php echo $noten['einser']; ?></td>
        </tr>
        <tr>
            <td>Zweier</td>
            <td><?php echo $noten['zweier']; ?></td>
        </tr>
        <tr>
            <td>Dreier</td>
            <td><?php echo $noten['dreier']; ?></td>
        </tr>
        <tr>
            <td>Vierer</td>
            <td><?php echo $noten['vierer']; ?></td>
        </tr>
        <tr>
            <td>Fünfer</td>
            <td><?php echo $noten['fuenfer']; ?></td>
        </tr>
        <tr>
            <td><strong>Durchschnitt</strong></td>
            <td><strong><?php echo $durchschnitt; ?></strong></td>
        </tr>
        <tr>
            <td>Beste Note</td>
            <td><?php echo $besteNote; ?></td>
        </tr>
        <tr>
            <td>Schlechteste Note</td>
            <td><?php echo $schlechteNote; ?></td>
        </tr>
        <tr>
            <td>Anzahl positive Noten (1-4)</td>
            <td><?php echo $positiveNoten; ?></td>
        </tr>
    </table>
    
    <br>
    <form method="post">
        <input type="submit" name="loeschen" value="Neu eingeben">
    </form>
    <?php

}
?>
```
