# PHP Grundlagen Cheatsheet (Basierend auf W3Schools)

Ein kompaktes Nachschlagewerk für die wichtigsten PHP-Befehle und -Konstrukte.

---

## 1. Syntax & Grundstruktur
PHP-Code wird in spezielle Tags eingebettet. Jede Anweisung muss mit einem Semikolon (`;`) beendet werden.

```php
<?php
// PHP Code steht hier

// Ausgabe auf dem Bildschirm
echo "Hallo Welt!";
print "Hallo Welt!";
?>
```

---

## 2. Variablen & Datentypen
Variablen beginnen immer mit einem Dollarzeichen (`$`). PHP erkennt Datentypen automatisch (*loosely typed*).

```php
<?php
$txt = "W3Schools";
$x = 5;
$y = 10.5;
$isTrue = true; // Boolean

// Variablenverkettung mit dem Punkt-Operator (.)
echo "Ich lerne PHP auf " . $txt;
?>
```

### Konstanten
Konstanten sind global und können nach der Definition nicht mehr verändert werden.
```php
<?php
define("GREETING", "Willkommen bei W3Schools!");
echo GREETING;
?>
```

---

## 3. Operatoren
* **Arithmetische Operatoren:** `+`, `-`, `*`, `/`, `%` (Modulo), `**` (Exponentiation)
* **Zuweisungsoperatoren:** `=`, `+=`, `-=`, `*=`, `/=`
* **Vergleichsoperatoren:** 
  * `==` (gleich)
  * `===` (identisch – gleicher Wert und gleicher Datentyp)
  * `!=` oder `<>` (ungleich)
  * `>`, `<`, `>=`, `<=`
* **Logische Operatoren:** `and` / `&&`, `or` / `||`, `not` / `!`

## 4. Kontrollstrukturen (Bedingungen)

```php
<?php
$t = date("H"); // Aktuelle Stunde im 24-Stunden-Format

if ($t < "10") {
    echo "Guten Morgen!";
} elseif ($t < "20") {
    echo "Guten Tag!";
} else {
    echo "Gute Nacht!";
}

// Switch-Anweisung
$favcolor = "red";
switch ($favcolor) {
    case "red":
        echo "Deine Lieblingsfarbe ist rot!";
        break;
    case "blue":
        echo "Deine Lieblingsfarbe ist blau!";
        break;
    default:
        echo "Deine Lieblingsfarbe ist weder rot noch blau!";
}
?>
```

## 5. Schleifen (Loops)

```php
<?php
// While-Schleife
$x = 1;
while ($x <= 5) {
    echo "Die Zahl ist: $x <br>";
    $x++;
}

// For-Schleife
for ($i = 0; $i <= 10; $i++) {
    echo "Die Zahl ist: $i <br>";
}

// Foreach-Schleife (speziell für Arrays)
$colors = array("rot", "grün", "blau", "gelb");
foreach ($colors as $value) {
    echo "$value <br>";
}
?>
```

---

## 6. Arrays
Arrays speichern mehrere Werte in einer einzigen Variablen.

```php
<?php
// 1. Indizierte Arrays (numerische Schlüssel)
$cars = array("Volvo", "BMW", "Toyota");
echo $cars[0]; // Ausgabe: Volvo

// 2. Assoziative Arrays (benannte Schlüssel)
$age = array("Peter" => "35", "Ben" => "37", "Joe" => "43");
echo "Peter ist " . $age['Peter'] . " Jahre alt.";

// 3. Mehrdimensionale Arrays
$cars = array (
  array("Volvo", 22, 18),
  array("BMW", 15, 13),
  array("Saab", 5, 2)
);
?>
```

## 7. Funktionen
Eigene Funktionen lassen sich einfach definieren und wiederverwenden:

```php
<?php
// Funktion definieren
function schreibeNachricht($name) {
    echo "Hallo $name!<br>";
}

// Funktion aufrufen
schreibeNachricht("Max");

// Funktion mit Rückgabewert
function addiere($x, $y) {
    return $x + $y;
}
echo "5 + 10 = " . addiere(5, 10);
?>
```

## 8. Formulardaten verarbeiten (`$_GET` & `$_POST`)
Über Superglobals greift PHP auf Formulardaten zu.

* **`$_GET`**: Sammelt Daten aus Formularen mit `method="get"` (Daten hängen sichtbar an der URL).
* **`$_POST`**: Sammelt Daten aus Formularen mit `method="post"` (Daten werden unsichtbar übertragen).

```php
<!-- HTML-Formular -->
<form action="welcome.php" method="POST">
  Name: <input type="text" name="fname">
  <input type="submit" value="Absenden">
</form>
```

```php
<!-- welcome.php -->
<?php
// Zugriff auf die POST-Daten
if(isset($_POST['fname'])) {
    $name = htmlspecialchars($_POST['fname']);
    echo "Willkommen " . $name;
}
?>
